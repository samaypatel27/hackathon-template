Hackathon Starter Setup

Fill in your keys, test them, then let this page write the .env files and install everything. Nothing is saved to disk until you click Generate .env files in step 4.

1. Anthropic API key

Create a key at console.anthropic.com → API Keys. It starts with sk-ant-. Your account needs a few dollars of credit for the test call.

2. Supabase

  1. Create a project at supabase.com/dashboard (wait ~1 min for it to provision).
  2. Project URL: Project Settings → Data API (or the Connect button at the top). Looks like https://abcdefgh.supabase.co.
  3. Keys: Project Settings → API Keys. Use the anon / publishable key and the service_role / secret key. The service role key stays in the backend only.
  4. Also enable Google: Authentication → Sign In / Providers → Google. Paste the Google Client ID + Secret from step 3 there.

3. Google OAuth

  1. In Google Cloud Console → APIs & Services → Credentials, set up the OAuth consent screen (External). While it's in Testing mode, add your Google account under Test users.
  2. Create credentials → OAuth client ID → Web application.
  3. Under Authorized redirect URIs, add the URI below. Copy it with the button so it matches exactly.
  4. Click Create, then copy the Client ID and Client secret here.

Optional: confirm the redirect URI with a real sign-in

Google only checks the redirect URI during a real sign-in. This opens Google in a new tab. If you land on a green ✓ page, the URI is registered correctly. Port 5000 must be free (don't start the backend yet).

4. Write & Install

a. Write the config files

Creates backend/.env and frontend/.env. If they already exist, only these keys are updated and anything else you added is kept.

b. Install dependencies

Runs npm install in frontend/, and creates backend/venv + runs pip install -r requirements.txt. Takes 1–3 minutes.

  • • Frontend: npm install
  • • Backend: venv + pip install

          

        


        

      


      
      

        
✓ Setup complete

        
Everything is configured and installed. You can stop this wizard (Ctrl+C in its terminal). From now on you only need these two commands, each in its own terminal, starting from the repo folder:

Terminal 2: frontend

          
cd frontend && npm run dev
